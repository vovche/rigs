Rigs 1.0 is the first stable release.

### Highlights
- **Failures explained.** When a machine or container does not start, stop or connect, Rigs shows the likely cause (missing folder, busy port, no KVM access, name conflict, out of memory…) and a command you can copy. Nothing fails silently any more.
- **One way to add resources.** The new “Add Resource” window lists containers and libvirt machines found on this computer, and reads `compose.yaml` or `run-vm.sh` to fill in the settings for you.
- **Packages.** Install on Ubuntu 24.04+ / Debian 13+ (`.deb`), Fedora 42+ (`.rpm`) or Arch Linux (`.pkg.tar.zst`). See the [install page](https://vovche.github.io/rigs/#install).

### Notes
- Flatpak is not supported on purpose: a sandbox cannot see the processes and sockets of your virtual machines.
- Verify downloads with `sha256sum -c SHA256SUMS`.
