# Work Packet: Windows driver installation through QGA

## Owned targets
- src/windows_guest_installer.vala
- tests/test_windows_guest_installer.vala

## Contract/dependencies
GuestAgent (other worker) virtual command(VmModel,string,Json.Object?=null,uint=5000)
returns unwrapped Json.Node; virtual reboot(VmModel). Parent adds
GuestToolsArtifact : Object public strings path,sha256,version; public bool iso;
constructor GuestToolsArtifact(string path,string sha256,string version="",bool iso=false).
Path is local readable EXE, sha256 64hex from pinned catalog or user file digest;
Windows Authenticode is required independently. Parent owns download/catalog/UI.

Implement `GuestToolsProbe : Object` fields bool available,compatible,administrator,
balloon_service_running; string architecture,version,summary (safe defaults).
`GuestInstallState` enum SUCCEEDED, REBOOT_REQUIRED, FAILED, TIMED_OUT.
`GuestInstallResult : Object` fields state,summary,journal_path,remote_directory;
int exit_code=-1. constructor convenient.
`WindowsGuestInstaller(GuestAgent? agent=null,string? state_dir=null)`.
Methods `public GuestToolsProbe probe(VmModel vm) throws Error`,
`public GuestInstallResult install(VmModel vm,GuestToolsArtifact artifact,uint timeout_ms=600000) throws Error`.
`public void reboot(VmModel vm) throws Error` delegates, never invoked by install.
`public signal void progress(string message)` (worker thread; UI marshals).

## Behavior
probe read-only: guest-info enabled supported_commands must include guest-get-osinfo,
guest-exec/guest-exec-status + guest-file-open/write/read/close for install;
guest-get-osinfo id mswindows, machine x86/x86_64; restrict automatic install to
Windows 10+/modern Server (version-id 10,11,2016,2019,2022,2025; others manual).
Fixed PowerShell via guest-exec (powershell.exe -NoProfile -NonInteractive
-EncodedCommand UTF16LE base64), capture-output true, poll guest-exec-status
bounded with get_monotonic_time; parse base64 JSON output. Preflight script only
reads admin token/OS and BalloonService; no arbitrary caller-supplied commands.
If unsupported, never upload/run installer. Treat malformed payloads as errors.

Install performs fresh probe + admin check. Recompute local EXE SHA-256
(streaming, max256MiB, reject iso and non-MZ file) against artifact.sha256.
Create unique guest directory C:\ProgramData\Rigs\GuestTools\<UUID> using fixed
PowerShell. Upload EXE via guest-file-open wb then 64KiB base64 writes,
check write count (partial writes handled or fail), close in finally.
Execute fixed PS script: verify guest SHA256 equals expected hex; verify
Get-AuthenticodeSignature Status=Valid and certificate simple name exactly
Red Hat, Inc. / Red Hat, Inc / Red Hat Inc. / Red Hat Inc (no substring signer
acceptance). Never install root certs/disable signature policy. Only after both
checks start exe /install /quiet /norestart /log <guest log> with wait.
Never install unauthenticated bytes. Keep path/hash substitutions escaped,
paths generated by module and hash validated, no user-controlled PS snippets.
Bundle installation may restart QGA: script writes durable outcome.json inside
job directory, including code/reboot/service result; poll guest-exec-status
but recover from lost PID/agent reconnect by reading outcome.json through
QGA file APIs. Codes0=>verify BalloonService exists/running, 3010=>reboot required;
1641=>unexpected reboot started (must not falsely succeed), other=>failed.
Do not report service verified until checked; no unconditional success.
On timeout do not kill msiexec or reboot; report status unknown + guest log path.
Write per-job host JSON journal under state_dir (default XDG state/rigs/guest-tools),
private directories/files; include resource key hash, phase, PID/job path,
package version/SHA, final result. Never log arbitrary guest stdout, credentials
or entire requests. Avoid duplicate concurrent installs per resource; lock key
from VM id or stable target plus transport. Tests use temp state_dir only.

## Tests
Class Rigs.Tests.TestWindowsGuestInstaller methods test_probe,test_install,
test_failures,test_scripts (can expose pure fixed-script builders for assertions).
Fake GuestAgent only, temp MZ fixture bytes. Verify unsupported/disabled QGA =>
no mutation, unsigned/hash mismatch => failed/no success, upload partial =>error,
3010=>reboot required (zero reboot calls), successful signed outcome + service,
malformed output, timeouts/reconnect via outcome, local journals. Inspect actual
fixed PS source for signature+hash checks before Start-Process, norestart and
no policy bypass. Do not run PowerShell/installer or contact any user VM.
Keep all test sleep waits tiny, whole suite <1s; test interval injection allowed.
